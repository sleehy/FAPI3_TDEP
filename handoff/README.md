# Colab ↔ local TDEP handoff

Each `iteration_XX/` directory is a deliberately minimal GitHub handoff. It
may contain only the six native TDEP fitting inputs, `manifest.json`, and the
resulting `outfile.forceconstant`. Do not add snapshots, SevenNet checkpoints,
`.npy` arrays, plots, or full `tdep_tetragonal_*/` directories here.

The commands and the commit/pull sequence are documented in the repository
root README.
